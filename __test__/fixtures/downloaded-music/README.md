These are generated silence samples (0.03 seconds), not downloaded music.
Each contains a synthetic encrypted NetEase comment for musicId 12345 and title
"Scanner fixture". FLAC and Ogg store it in DESCRIPTION; the others use comment.
They were generated with FFmpeg to exercise actual container parsers, including
Vorbis, ID3, MP4, RIFF, AIFF, APEv2 and ASF tags. Tests do not require FFmpeg.
